# Cozy Day!

*A little adventure for your day.*

A small cozy browser game where you choose a tool and receive a daily task.

---

### Tools

🌱 **Plant** — Plant something today  
💧 **Water** — Water your plants  
🪓 **Axe** — Cut down a tree  
⛏️ **Pickaxe** — Mine some resources

### Built With

`HTML` · `CSS` · `JavaScript`

### About

I created this project to refresh my HTML, CSS, and JavaScript skills while building something fun and interactive.
